# NoNameTutor

Class 9 Physics study workspace.

## Initial curriculum
- Chapter 4 — Describing Motion Around Us
- Chapter 6 — How Forces Affect Motion
- Chapter 7 — Work, Energy, and Simple Machines

## Current philosophy
This first build is intentionally **pre-written and provider-free**. It proves the core learning UX before an AI layer is introduced.

## Roadmap
1. Curriculum/content system
2. Better chapter reader
3. Practice engine and answer checking
4. Notes and flashcards
5. Student accounts and persistent progress
6. Optional grounded AI tutor
7. Adaptive mastery and spaced repetition

Run with `npm install` then `npm run dev`.
